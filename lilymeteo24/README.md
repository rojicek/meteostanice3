# lilymeteo24

lily pi meteostanice v 2024

tohle je realne bezici kod

board: TTGO T-Watch

`Tools > Board > Boards Manager > ESP32 by Espressif Systems` verze 2.0.14 (s 3.x se lily lib neprelozi)

knihovny: 

- ESP32Time

- Time

- ArduinoJson

- lily lib (extra soubor)

hesla (wifi, server):

- zkopirovat `secrets.h.example` na `secrets.h` a vyplnit hodnoty

- `secrets.h` je v `.gitignore`, na GitHub se nedostane
